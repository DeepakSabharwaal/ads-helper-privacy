Ads Helper

Privacy Policy — last updated August 21, 2026

No data ever leaves your browser

Ads Helper has no servers, no analytics, and no third-party services. It never transmits information to the developer or to anyone else — only to the ad platforms you are already signed in to.

Stored on your device only

  • Your popup preferences — whether ads tabs refresh after an extension reload, and whether Copy ads as images is enabled.
  • Undo history for bulk edits (for example, headline text with its previous and new values) so the Undo button can restore prior values. Stored locally in your browser, never transmitted.

Authentication data — Meta Ads Manager

When you use the Meta Ads Manager report export, the extension reuses the session credential Ads Manager has already placed in your browser. That credential is handled as follows:

  • 1 Read from the page’s own network activity, only at the moment you click the report button.
  • 2 Sent only to Meta’s own API server (adsmanager-graph.facebook.com) — the same server Ads Manager is already talking to — for read-only requests that fetch your report data.
  • 3 Never stored, logged, or forwarded anywhere else. The extension never sees or handles your passwords on any platform.

Permissions explained

4 ad platform sites

Required to inject the bulk-editing UI into Google Ads, Microsoft Advertising, Meta Ads Manager, and LinkedIn Campaign Manager. The extension cannot run on any other site.

storage

Saves the two popup preferences and your undo history locally in Chrome. Nothing is synced or uploaded.

webNavigation

Used only by the Run diagnostic button to query editor frames inside the current ads tab. Not used at any other time.

optional — all sites

Requested only if you enable Copy ads as images in the popup. Chrome’s screen-capture API requires broad host access; without this toggle it is never requested. You can revoke it at any time from the popup.
