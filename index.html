Ads Helper — Privacy Policy

Last updated: August 21, 2026

Ads Helper is a bulk-editing tool for the ad platform editors of Google Ads, Microsoft Advertising, Meta Ads Manager, and LinkedIn Campaign Manager. It is designed so that no data ever leaves your browser except requests to the ad platforms you are already using.

What the extension collects

Nothing. Ads Helper has no servers, no analytics, no tracking, and no third-party services. It never transmits any information to the developer or to anyone else.

What the extension stores on your device

  • Your two popup preferences (whether ads tabs refresh after an extension reload, and whether “Copy ads as images” is enabled).
  • Undo history for bulk edits (for example, campaign names with their previous and new values) so the Undo button can restore prior values. This is stored locally in your browser and never transmitted.

Authentication data

When you use the Meta Ads Manager report feature, the extension reuses the session credential that Ads Manager itself has already created in your browser. That credential is:

  • read from the page’s own network activity, only at the moment you click the report button;
  • sent only to Meta’s own Ads Manager API server (adsmanager-graph.facebook.com) — the same server the page is already talking to — for read-only requests that fetch your report data;
  • never stored, logged, or sent anywhere else.

The extension never sees or handles your passwords on any platform.

Permissions

  • Access to the four ad platform sites — required to add the bulk-editing buttons to those editors. The extension cannot run anywhere else.
  • Storage — for the local preferences and undo history described above.
  • webNavigation — used only by the “Run diagnostic” button to reach editor frames inside the current ads tab.
  • Optional access to all sites — requested only if you switch on “Copy ads as images”, which needs Chrome’s screen-capture permission. It is off by default and can be revoked at any time in the popup.
